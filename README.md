# Café Aurora ☕

Landing page de uma cafeteria fictícia desenvolvida com HTML5 e CSS3.

## 🌐 Projeto online

Acesse:
https://viniaquino-dev.github.io/projeto-cafe-aurora/

## 🛠 Tecnologias

- HTML5
- CSS3

## 📚 Conceitos praticados

- HTML semântico
- Box Model
- Unidades em rem
- Position
- Inline-block
- Pseudo-classes
- Formulários
- Gradientes
- Sombras
- Background images
- Sticky e fixed positioning

## 🎯 Objetivo

Projeto desenvolvido para consolidar os fundamentos de HTML e CSS antes do início dos estudos em JavaScript.
